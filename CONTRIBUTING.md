# Bidra til 9. trinn matematikk

## Før du endrer innhold

1. Les `README.md`, `CURRICULUM_MAP.md`, `AI_WORKFLOW.md` og bokstandarden.
2. Kontroller om endringen berører et kompetansemål eller en dokumentert beslutning.
3. Bruk en egen branch for større endringer.
4. Hold endringer små og tydelige.

## Krav til faginnhold

- Oppgi relevante kompetansemål.
- Kontroller alle matematiske svar uavhengig.
- Skill mellom eksempel, oppgave og løsningsforslag.
- Kontroller at nødvendige forkunnskaper er introdusert.
- Bruk korrekt norsk matematisk terminologi.

## Review før merge

- Matematisk kontroll.
- Pedagogisk og redaksjonell kontroll.
- Visuell kontroll av faktisk rendering.
- Teknisk build og lenkekontroll.
- Oppsummer hva som er testet og hva som gjenstår.

Ikke publiser eller merk materiale som godkjent før nødvendige kontroller er gjennomført.
