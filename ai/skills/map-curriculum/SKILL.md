# Skill: Map curriculum

## Goal

Create a defensible curriculum map for a mathematics textbook. This skill is for curriculum analysis, not chapter writing.

## Inputs

- Current official Udir curriculum and version.
- Target grade and adjacent grades.
- Existing curriculum map and book standards.
- Any known teaching-time or school-year constraints.

## Procedure

1. Verify the currently valid curriculum version and effective date on Udir.
2. Retrieve the complete competence aims for the target grade and adjacent grades.
3. Read relevant explanation texts, core elements, basic skills and assessment guidance.
4. Preserve the official aim wording or link to it; distinguish quotation from editorial summary.
5. Break each aim into observable knowledge, skills, representations and reasoning.
6. Identify prerequisite knowledge from the previous grade.
7. Identify how the target-grade learning contributes to the next grade.
8. Mark cross-cutting concepts and skills.
9. Propose possible teaching sequences only after the mapping is complete.
10. Run a coverage check: every target-grade aim must map to at least one planned section and a way to assess learning.

## Output

A table with:
- Curriculum aim / stable identifier
- Official source URL and version
- Explanation text / interpretation
- Prerequisites
- Target-grade learning outcome
- Planned book section (provisional until approved)
- Evidence or assessment opportunity
- Open questions

Also include a progression summary across the adjacent grades and a list of assumptions requiring teacher review.

## Quality rules

- Never use an outdated curriculum version as current.
- Never infer that a topic is forbidden or absent simply because it is not explicitly named in one grade's aims.
- Do not treat a proposed textbook chapter sequence as an official Udir sequence.
- Do not claim full coverage if any aim is unmapped.
- Flag ambiguous interpretation rather than silently choosing one.
- Cite official sources for every curriculum-dependent claim.
